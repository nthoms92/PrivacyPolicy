# PrivacyPolicy
Last updated: September 30, 2026

This Privacy Policy describes how I handle information when using this application to access and manage files stored in my personal Google Drive account through the Google Drive API.

This application is intended for personal use and is not operated as a commercial service or provided to other users.
Information Accessed

The application may access information from my Google Drive account as authorized through Google's OAuth authorization process. Depending on the permissions granted, this may include:

    Files and folders stored in my Google Drive.

    File names, file types, folder structures, and other file metadata.

    The contents of files that are transferred between Google Drive and my local storage.

    OAuth authentication credentials necessary to maintain authorized access to Google Drive.

The application only requests and uses the permissions necessary for its intended purpose.
How Information Is Used

Google Drive data accessed by this application is used solely for my personal file synchronization, backup, storage, and file-management purposes through rclone.

The application does not use Google Drive data for advertising, profiling, marketing, data analytics, or any commercial purpose.
Data Sharing

I do not sell, rent, or otherwise provide my Google Drive data to third parties.

Google Drive data accessed through the application is not shared with external parties except where necessary for the normal operation of services that I have personally configured, such as Google Drive itself or my own storage systems.
Data Storage

Files downloaded from Google Drive may be stored on computers, storage devices, or other storage services that I personally control or have configured for use with rclone.

OAuth credentials and tokens may also be stored locally so that the application can maintain authorized access without requiring repeated authorization.

I take reasonable steps to protect locally stored credentials and data from unauthorized access.
Data Retention

Google Drive data is retained according to my personal storage and backup practices.

OAuth credentials are retained only for as long as they are needed to maintain authorized access to Google Drive. They may be deleted or revoked at any time.

I can revoke the application's access to my Google Account through Google's account security settings.
Google API Services

This application uses the Google Drive API to access Google Drive data. Use of Google API Services is subject to Google's applicable terms and policies.

Google's policies regarding API access and user data can be found in the Google API Services User Data Policy and Google Drive API documentation.
Security

I take reasonable precautions to protect information accessed through the application. However, no method of electronic storage or transmission can be guaranteed to be completely secure.

Because this application is configured for personal use, access to the application, credentials, and resulting data is restricted to me and systems that I have authorized.
Children's Privacy

This application is not directed toward children under the age of 13 and is not intended to collect personal information from children.
Changes to This Privacy Policy

I may update this Privacy Policy if the application's use of Google Drive or its data practices change. Any updated version will be published at this location with a revised "Last updated" date.
